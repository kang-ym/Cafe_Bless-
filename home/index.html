📌 Cafe Bless 관리자 페이지 사용 설명

☕ 1. Today's Orders - 오늘의 주문 확인

  • 📦 주문 리스트에서 ‘完了’ 체크박스를 눌러 확인 표시를 합니다.
  • 버튼을 누르면 체크된 주문만 가계부로 전송됩니다.
  • 전송된 주문은 送信完了으로 표시됩니다.

💰 2. Cafe Ledger - 카페 가계부

  • 👤 チャージ 버튼을 눌러 잔액을 충전할 수 있습니다.
  • 버튼을 누르면 삭제 모드로 전환됩니다. 원하는 이름을 선택 후 삭제 가능
  • 👪 아이콘을 누르면 그룹 구성원 리스트가 펼쳐집니다.
  • 👶 게스트 그룹의 경우:
    • 📝 이름을 클릭하여 자유롭게 수정할 수 있습니다.
    • 📤 移動 버튼을 이용해 게스트를 다른 그룹으로 이동시킬 수 있습니다.
  • ➕ 사람 추가: 그룹별로 새로운 사람을 추가할 수 있습니다. 초기 잔액도 설정됩니다.

🍱 3. Lunch Ledger - 점심 가계부

  • 💵 チャージ 입력창에 금액을 입력하고 버튼을 눌러 충전합니다.
  • -200 버튼을 누르면 점심값이 자동 차감됩니다.
  • → 삭제할 사람을 선택 후 削除할 수 있습니다.
  • ➕ 사람 추가: 선택된 그룹에 점심 Ledger 전용 사용자 추가 가능 (기본 잔액 0으로 시작)
